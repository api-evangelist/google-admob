# Google AdMob

> AdMob is Google's mobile app advertising and monetization platform. The AdMob API
> (admob.googleapis.com) gives publishers programmatic access to their AdMob account,
> apps, ad units, ad sources, adapters, ad unit mappings and mediation groups, and
> generates network, mediation and campaign performance reports. It is a REST/JSON API
> authorized with Google OAuth 2.0 user tokens (service accounts are NOT supported).
> Two channels share one host: v1 is stable and entirely READ-ONLY (6 operations);
> v1beta carries the whole write surface plus campaign reporting (19 operations).

## What is machine-readable

Google publishes NO OpenAPI for AdMob. The first-party machine-readable contract is a
Google Discovery Document served by the API host itself, and a protobuf IDL published
in googleapis/googleapis. Both are harvested here; the OpenAPI in this repo was
converted from the Discovery Document by API Evangelist.

- [AdMob v1 Discovery Document](https://admob.googleapis.com/$discovery/rest?version=v1): first-party contract, revision 20260731
- [AdMob v1beta Discovery Document](https://admob.googleapis.com/$discovery/rest?version=v1beta): first-party contract, revision 20260731
- [admob_api.proto](https://github.com/googleapis/googleapis/blob/master/google/ads/admob/v1/admob_api.proto): service AdMobApi, 4 RPCs (v1 only)

## APIs

- [AdMob API v1](https://developers.google.com/admob/api): stable, read-only. accounts_get, accounts_list, accounts_apps_list, accounts_adUnits_list, accounts_networkReport_generate, accounts_mediationReport_generate
- [AdMob API v1beta](https://developers.google.com/admob/api): beta, read + write. Adds ad sources and adapters, ad unit mappings (single and batch), app and ad unit creation, mediation group create/list/patch, mediation A/B experiment create/stop, and campaign reporting

## How to call it

- [Get started](https://developers.google.com/admob/api/v1/getting-started): enable admob.googleapis.com on a Google Cloud project, create an OAuth client, consent as an AdMob user
- Auth: OAuth 2.0 authorization code. Authorize at https://accounts.google.com/o/oauth2/v2/auth, exchange at https://oauth2.googleapis.com/token
- Scopes: https://www.googleapis.com/auth/admob.readonly and https://www.googleapis.com/auth/admob.report
- Service accounts are not supported. A human must consent; there is no unattended credential.
- [API reference](https://developers.google.com/admob/api/rest)

## Runtime rules an agent must know

- Quotas are per Google Cloud project: 900 account reads/min, 120 inventory reads/min, 172,800 inventory reads/day, 900 reporting reads/min
- Exhaustion returns HTTP 429 RESOURCE_EXHAUSTED. There is NO Retry-After and no RateLimit-* header — back off on a client-side schedule
- Errors are google.rpc.Status under an `error` key, not RFC 9457 problem+json
- There is NO idempotency key. Every v1beta write (create app, ad unit, ad unit mapping, mediation group, A/B experiment) can duplicate on retry — re-read the parent collection instead of blindly retrying
- There is NO sandbox. Every call hits the real account; v1beta writes create real production inventory
- Reports cap at 100,000 rows per request; over that is a 400 INVALID_ARGUMENT, not a page
- Revenue is returned as microsValue (millionths of the account currency), not a decimal
- Paging is Google-standard pageSize / pageToken / nextPageToken
- accounts_mediationGroups_patch requires updateMask; omitting it overwrites fields you did not intend to change

## Not present

- No OpenAPI published by Google
- No AsyncAPI, no webhooks, no event or streaming surface of any kind
- No MCP server, no A2A agent card (probed /.well-known/agent-card.json and /.well-known/agent.json on every host — all 404)
- No CLI, no embeddable UI components for the API
- No deprecation policy, no Sunset/Deprecation headers, no SLA
- No /.well-known/ documents on admob.googleapis.com
- No priced API plans — AdMob pays publishers a revenue share; API access is free within quota
